# Tests

Две реальные проверки этапа 0, без подставных тестов:

- `SilenceAndMidiSmoke.cpp` — консольная цель `XenMilenium_Smoke`. Создаёт процессор, подаёт стереобуфер с ненулевыми и NaN-сэмплами и MIDI (note-on, note-on с velocity 0, note-off, второй note-on). Ждёт точные нули в обоих каналах и счётчик: последняя нота 64, два note-on. Отдельно проверяет обход (bypass) и блок нулевой длины.
- `check_vst3_identity.py` — читает собранный `moduleinfo.json` и `.so`. Проверяет имя `Xen Milenium`, производителя `XenMilenium`, категории Instrument/Synth и отсутствие идентификаторов XEN 2000.

Загрузка в DAW здесь не проверяется.

С этапа 1.7 та же цель печатает `matrix ok` перед `smoke ok`: MSEG, слоты матрицы, старые маршруты, пресет и блоки 1…1024. Это проверка сигнала, не список параметров.
