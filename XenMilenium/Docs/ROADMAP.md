# Дорожная карта Xen Milenium

Функции добавляются короткими этапами. Следующий этап не начинается, пока текущий не собран и не проверен, а для звукового кода — пока его отдельно не подтвердят.

Что строить, решает `TECHNICAL_SPEC.md`. DUNE 2 — ориентир поведения и интерфейса. Возможности DUNE 3 входят только там, где спецификация прямо их назвала: типы Chorus и JP Flanger у хоруса и характер Fuzz. Закрытый DSP, заводские таблицы, пресеты и ассеты DUNE не считаются воспроизведёнными. Звук с оригиналом не сравнивался.

Каркас этапа 0 — не движок. Восемь партий в нём не реализованы.

## Этап 0 — каркас VST3

Сделано. Release VST3 собран на Linux. Плагин называется `Xen Milenium`, принимает MIDI и пишет тишину в стереовыход. Подробности — в `STAGE0_REPORT.md`. На этапе 0.1 дерево перенесено в каталог `XenMilenium/`, корневая сборка TetraOP восстановлена.

## Дальше, только после подтверждения

Порядок можно сузить, но не перескакивать через состояние и MIDI: иначе осциллятор окажется без партий.

1. Идентификаторы параметров и документ пресета версии 1. Звука нет. Проверка — цикл сохранения.
2. Восемь партий, включение, громкость, маршрутизатор MIDI, по-прежнему тишина. Проверка — кто принял ноту.
3. Аллокатор голосов, лимиты стенда, Note Off, Sustain, Pitch Bend, Mono и Legato. Выход всё ещё может быть тишиной, но счётчики голосов обязаны совпасть со спецификацией.
4. Огибающие Amp и Filter без тембра: амплитуда тестового сигнала или продолжение тишины, если тестовый сигнал ещё не утверждён.
5. Три осциллятора: Basic Shapes, общий выход, микшер OSC1, OSC2, RING, NOISE, Direct Out. Без модификаторов.
6. Модификаторы по одному, начиная с PW и Noise, затем Sync, FM, Bend.
7. Основной фильтр: сначала LP/HP/BP 12 и 24 dB, затем остальные типы и насыщение.
8. Четыре LFO, матрица, затем MSEG.
9. FX по одному типу на партию. Multiband — последним внутри компрессора, после замера обычного режима.
10. Страницы GUI вместо временного окна. Редактор wavetable — отдельным шагом после того, как таблицу можно выбрать.
11. Заводские банки Xen, если они будут заказаны. Банки DUNE не импортируются.

Каждый шаг ограничен своими тестами из `CPU_AND_DSP.md`. Нагрузка относительно DUNE на дорожную карту не ставится.
