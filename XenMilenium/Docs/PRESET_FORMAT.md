# Формат состояния Xen Milenium

Свой формат проекта. Файлы FXP и банки DUNE не читаются и не пишутся. Заводские пресеты DUNE, таблицы и рисунки в поставку не входят.

## Что хранит документ

Один документ — полное состояние инструмента:

- версия формата;
- глобальные поля: мастер-громкость, размер и страница GUI, фокус партии, режим редактирования;
- восемь партий, включая выключенные;
- у каждой партии три осциллятора, фильтр, огибающие Amp и Filter, четыре LFO, четыре MSEG, матрица, FX1 и FX2 вместе с порядком слотов;
- встроенные пользовательские таблицы, если партия на них ссылается;
- ничего из чужого синтезатора.

GUI-поля, которые не влияют на звук, лежат в том же документе, но в отдельном объекте `ui`. Хост, который сохраняет состояние плагина, пишет весь документ. Пресет на диске может содержать `ui`, а загрузка пресета **по предложению** не трогает размер окна и страницу, если в диалоге не выбран пункт «загрузить и вид». **Открытый вопрос:** сохранять ли вид внутри пользовательского пресета по умолчанию. Звуковые поля загружаются всегда.

## Слои файлов

| Слой | Кто пишет | Содержимое |
| --- | --- | --- |
| Состояние хоста | DAW | Полный документ в блоке VST3 |
| Заводской банк | поставка Xen, только чтение | Документы без чужих семплов |
| Пользовательский пресет | пользователь | Один документ |
| Банк | папка пресетов | Не отдельный бинарный контейнер |
| Ресурс таблицы | заводской каталог или вложение в документ | Кадры wavetable |
| Пресет MSEG | файл одной кривой | Импорт в MSEG партии |

Банк — каталог. Имя банка — имя каталога. Это организационный принцип, похожий на папки Soundbanks в разделе управления патчами DUNE 2, но расширение файла и байты другие. Сканирование чужих каталогов DUNE не выполняется.

Заводской слой нельзя перезаписать командой Save. Save As в заводской банк не пишет. Пользовательский слой — каталог пользователя, путь подтверждается отдельно и не является системной папкой VST3.

## Идентификаторы

Параметр именуется устойчивым строковым путём. Числовые ID другого проекта запрещены.

Примеры путей, они же контракт на будущее:

- `part/1/enabled`
- `part/1/volume`
- `part/1/osc/1/waveSource`
- `part/1/osc/1/wtPosition`
- `part/1/osc/1/modifier`
- `part/1/osc/3/directOut`
- `part/1/mixer/osc1`
- `part/1/mixer/ring`
- `part/1/mixer/noise`
- `part/1/filter/type`
- `part/1/filter/cutoff`
- `part/1/lfo/4/retrig`
- `part/1/mseg/1/points`
- `part/1/matrix/slot/1/source`
- `part/1/fx/1/order`
- `part/1/fx/2/slot/3/bypass`
- `master/volume`

Партии и индексы в путях нумеруются с 1, как на панели. Внутри движка массив может быть с нуля, но файл показывает номера панели.

Имя пути после выпуска формата не переименовывается. Новый параметр — новый путь. Старый путь при удалении функции остаётся в документе и игнорируется читателем, а не удаляется молча при первой загрузке.

Нормативный список путей, типы и правила нормализации — в `PARAMETER_SCHEMA.md`. `EMPTY_PRESET_EXAMPLE.json` загружается: `null` и отсутствующий зарегистрированный ключ получают значение реестра. Отсутствующий слот матрицы 2–32 значит пустой слот: источник `off`, назначение `off`, amount 0, enable false. Отсутствующий `enable` тоже false, поэтому старый документ без этого ключа слот не включает. Отсутствующий слот FX значит обойдённый слот без типа. Эти пропуски разрешены, чтобы пустой документ не повторял одно и то же сотни раз.

Ключи `notes` и `openQuestions` в примере — пояснение к файлу, не звуковые параметры. Загрузчик их игнорирует и в мешок `unknown` не кладёт. Значение `null` в примере тоже документальное: спецификация не задала plain-значение. Это не число 0 и не команда обнулить параметр при будущей загрузке.

Блок состояния хоста — тот же документ в UTF-8 JSON. Ключи параметров — пути состояния, не идентификаторы APVTS. `formatVersion` обязан быть целым `1`; иная версия, пустой блок и документ с чужим типом известного пути не применяются, прежнее состояние остаётся. Отсутствующий зарегистрированный путь получает значение по умолчанию реестра. Незарегистрированный путь попадает в `unknown.parameters`. Посторонний верхний ключ попадает в `unknown.document`. `embeddedWavetables` хранится массивом и не интерпретируется. Отсутствующий `ui` не заменяет уже открытый вид.

Значение — число, строка из замкнутого списка или вложенный объект (кривая MSEG, порядок FX). Список допустимых строк живёт рядом с версией формата.

## Версия и миграция

Поле `formatVersion` — целое, начиная с 1. Документ без поля или с версией выше поддерживаемой отклоняется целиком, параметры плагина не меняются, интерфейс показывает ошибку. Частичная загрузка неизвестной мажорной версии запрещена: иначе патч прозвучал бы наполовину.

Миграция — явная функция `N → N+1`. Цепочка применяется по порядку. Функция не переименовывает пути, а заполняет новые пути значениями по умолчанию или вычисляет их из старых.

Отсутствующий известный путь получает значение по умолчанию этой версии и помечается в журнале загрузки как «дополнено», без окна на каждый параметр. Неизвестный путь сохраняется в мешке `unknown` и пишется обратно при сохранении. Так постороннее поле будущей версии не стирается, если минорная добавка ещё не описана, но мажорная версия всё равно не грузится частично: мешок используется только когда `formatVersion` уже поддерживается и в ней появились необязательные расширения.

Повреждённый документ не применяется. Предыдущее состояние плагина остаётся.

## MSEG и таблицы

`formatVersion` остаётся 1. Миграции документа нет: новые ключи без записи получают значения реестра, а кривая не становится параметром.

`part/<n>/mseg/<k>/points` — массив объектов. Движок использует `duration` и `level`, не больше 8 элементов. Лишние элементы, нечисловые точки и незнакомые поля объекта при сохранении не выбрасываются, потому что путь остаётся в `unknown.parameters`. Неверный тип уже зарегистрированного пути, включая неизвестное имя источника слота, по-прежнему отвергает документ целиком. `polarity` и `scope` слота не зарегистрированы: их строки сохраняются и на звук не влияют.

Патч хранит четыре кривые каждой партии внутри этого массива. Отдельный файл одной кривой той же схемы в загрузчик не подключён. Загрузка такого файла партию не заменяет, потому что её нет.

Заводская таблица хранится ресурсом с идентификатором `wt/<name>` и в патч семплами не копируется, пока пользователь не отредактирует кадры. Отредактированная или импортированная таблица вкладывается в документ блоком `embeddedWavetables`, а осциллятор ссылается на этот блок. Тогда пресет переносится без внешнего файла. **Открытый вопрос:** максимальный размер вложения. До измерения предлагается отказ загрузки блока больше 8 МиБ на таблицу с сообщением, а не обрезка кадров.

Формат кадров (разрядность, число кадров, период) фиксируется в версии ресурса таблицы, не в идентификаторе параметра `waveSource`.

## Состояние хоста и файл

Блок VST3 хранит тот же документ, что Save. Load заменяет звуковое состояние всех восьми партий. Отмена загрузки — ответственность хоста; свой стек undo эта спецификация не требует.

Имена заводских пресетов Xen задаются при их появлении. На этапе спецификации банка пустые. Утверждение, что какой-либо пресет совпадает с патчем DUNE, запрещено.
